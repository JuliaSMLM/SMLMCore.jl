Tutorial

This tutorial builds two small localization data sets from constructed values, selects emitters from them, merges them, converts between positions and pixels, and cuts an ROI batch from an image. Every block runs as written with only SMLMCore loaded.

A camera

A camera gives the pixel geometry. Here: 128 × 128 pixels of 0.1 µm at the sample (a 10 µm sensor pixel behind a 100× objective), so the field of view is 12.8 µm across.

using SMLMCore

cam = IdealCamera(128, 128, 0.1)
IdealCamera{Float64} with:
  Dimensions: 128 × 128 pixels
  Pixel size: 0.1 μm
  Field of view: 12.8 × 12.8 μm

Positions are in µm with (0, 0) at the camera's top-left corner; x runs along the columns and y down the rows (Conventions).

Emitters and an SMLD

Each localization is an Emitter2DFit: position (µm), fitted signal (the total in the frame) and background per pixel (photons here; photoelectrons when a fitter converts sCMOS ADU), their standard deviations, and the frame and dataset it belongs to. These two acquisitions of the same field each have three frames; the second is shifted by 0.05 µm in x.

#               x      y     photons σ (µm) frame
const SPOTS = [(1.04,  2.02, 1500.0, 0.010, 1),
               (3.24,  4.16,  800.0, 0.025, 1),
               (5.53,  1.34, 2000.0, 0.008, 2),
               (7.42,  9.95,  600.0, 0.030, 3),
               (10.13, 6.68, 1200.0, 0.012, 3)]

acquisition(shift) = [
    Emitter2DFit{Float64}(x + shift, y, photons, 10.0, σ, σ, sqrt(photons), 1.0; frame = f)
    for (x, y, photons, σ, f) in SPOTS
]

a = BasicSMLD(acquisition(0.0), cam, 3, 1)    # 3 frames, 1 dataset
b = BasicSMLD(acquisition(0.05), cam, 3, 1)
a
BasicSMLD{Float64,Emitter2DFit{Float64}}:
  Emitters: 5 2D localizations
  Camera: 128×128 pixels
  Frames: 3
  Datasets: 1
  Mean photons: 1220.0
  Metadata keys: none

Selecting emitters

@filter keeps the emitters for which a condition on their properties holds:

precise = @filter(a, σ_x < 0.02 && photons > 1000)
[(e.x, e.y) for e in precise.emitters]
3-element Vector{Tuple{Float64, Float64}}:
 (1.04, 2.02)
 (5.53, 1.34)
 (10.13, 6.68)

A condition holds only property names, number literals and tuples. A threshold held in a variable is read as a property, so filter the emitter vector directly instead:

threshold = 1000.0
kept = filter(e -> e.photons > threshold, a.emitters)
bright = BasicSMLD(kept, a.camera, a.n_frames, a.n_datasets, copy(a.metadata))
length(bright)
3

filter_frames selects frames, and filter_roi a region, with inclusive bounds in µm:

early = filter_frames(a, 1:2)
[e.frame for e in early.emitters]
3-element Vector{Int64}:
 1
 1
 2
region = filter_roi(a, (0.0, 6.0), (0.0, 5.0))
[(e.x, e.y) for e in region.emitters]
3-element Vector{Tuple{Float64, Float64}}:
 (1.04, 2.02)
 (3.24, 4.16)
 (5.53, 1.34)

Each result is a new SMLD, but its emitters are the input's own objects: changing a field of region.emitters[1] changes a.emitters[1] too. deepcopy a result before changing its emitters.

Merging data sets

merge_smld combines SMLDs from the same camera. With adjust_frames and adjust_datasets, the second input's frames follow the first's, and each input keeps its own dataset number:

both = merge_smld(a, b; adjust_frames = true, adjust_datasets = true)
[(e.frame, e.dataset) for e in both.emitters]

(6, 2, Dict{String, Any}("dataset_adjustment" => true, "merged_from" => 2, "frame_adjustment" => true))

cat_smld concatenates without renumbering.

Positions and pixels

For square pixels with the camera's edges at 0, physical_to_pixel gives pixel coordinates (column, row), with (1, 1) at the center of the top-left pixel, and physical_to_pixel_index the pixel that holds a position:

e = a.emitters[2]
physical_to_pixel(e.x, e.y, 0.1), physical_to_pixel_index(e.x, e.y, 0.1)
((32.9, 42.1), (33, 42))

pixel_to_physical goes back, and get_pixel_centers lists every pixel center of a camera:

centers_x, centers_y = get_pixel_centers(cam)
pixel_to_physical(33, 42, 0.1), (centers_x[33], centers_y[42])
((3.25, 4.15), (3.25, 4.15))

An ROI batch

A fitter takes square ROIs cut from camera frames, as an ROIBatch. Images are indexed [row, column] = [y, x], and an ROI's corner is the camera pixel (column, row) of its top-left pixel. This frame has one bright pixel at each emitter of frame 1, and a 7 × 7 ROI is cut around each:

image = zeros(Float32, 128, 128)      # one frame, [y, x]
frame1 = filter_frames(a, 1)
pixels = [physical_to_pixel_index(e.x, e.y, 0.1) for e in frame1.emitters]   # (column, row)
for (col, row) in pixels
    image[row, col] = 100.0f0
end

roi_size = 7
x_corners = [col - roi_size ÷ 2 for (col, row) in pixels]
y_corners = [row - roi_size ÷ 2 for (col, row) in pixels]
data = cat([image[y:y+roi_size-1, x:x+roi_size-1] for (x, y) in zip(x_corners, y_corners)]...;
           dims = 3)                  # [y, x, roi]
batch = ROIBatch(data, x_corners, y_corners, fill(1, length(pixels)), cam)
ROIBatch{Float32} with:

  Data type: Array{Float32, 3}
  Camera: IdealCamera{Float64}
